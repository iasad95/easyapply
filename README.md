# LinkedIn GPT

Automates LinkedIn Easy Apply workflows with optional GPT-based form assistance.

## ⚠️ Disclaimer & Intended Use

This project is built **strictly for educational, research, and demonstration purposes** - particularly to explore **LLM (Large Language Model) integration**, browser automation, and workflow design.

Using automation tools on platforms like LinkedIn **may violate their Terms of Service** and can lead to:

- Temporary or permanent **account restrictions**
- Reduced visibility (**shadow banning**)
- **Account suspension or permanent ban**

**Use at your own risk.** The author does not encourage misuse and is not responsible for any consequences resulting from the use of this project.

This project is intended to demonstrate:

- AI/LLM-assisted workflows
- Automation of repetitive tasks
- Integration of GPT-style models into real-world pipelines

It is **not intended for production use or large-scale automation on live platforms**.
